# 冷柜内部模型与参数

维护责任：环境／资源、运输与科研维护者。

本页集中维护默认参数、热控与续航计算、航程曲线及实现接缝。玩法保证以[能力规格](../README.md)为准；涉及既有约束的调参须同步对应规格和实现，计算示例不能反向改写合同。读者使用说明见[机制指南](../../Docs/MECHANICS.md)。

便携睡垫：45布料／皮革加5鳞片，基础工作量900、质量3kg、最大耐久90，实际受材质等原生修正。独立睡袋休息基础1.05；装柜后继承原垫品质，并对柜床额外增加休息基础0.25、免疫系数×1.15、手术系数×1.10、包扎偏移0.05，再应用原生品质。冷柜床始终仅限前置认可涅瓦莲，通用运输乘员资格另计。

## 有偿拉温、维持与真实结算

只保存一个真实内温T；A为本步实际外温，S为目标。普通M=1，已解锁且开启PEPPER时M=3。物品直接使用柜内环境，不新增逐物比热、相变或独立物品温度。

### 被动交换与有偿温变

时间单位为游戏tick。被动系数k=0.00003/tick，CHIVE后为0.000015/tick；未付费时间始终指数趋近外界：

~~~text
T(t) = A + (T0 − A) exp(−kt)
d = sign(S − T)                         −1制冷，+1制热
L = k(A − T)                           自然瞬时温变率
v = 0.0125M °C/tick                     有偿净拉温基础速率
Tdot_paid = L + d[v + max(0, −dL)]
D = max(0, −d(A − S))                   阻碍当前动作的不利外温差
P_pull = M(120 + 4.8D) W
~~~

有利自然换热保留并叠加v，不收抵消费；不利自然换热只在实际有偿时抵消。外温恰好等于目标也可付费拉温。120W是持续拉温功率，不是固定启动费用，也不是在XML默认负载之外再叠一份同值费用。

首次达到T=S事件立即结束拉温项，剩余时段按允许方向维持。A>S需供冷，A<S需CREAM及电力供热；可实际供能时保持目标并付P_hold=4.8|A−S|M W。A=S自然稳定，无维持费用。快速模式维持费仍乘3，CHIVE不直接减此费用。

只有主动拉温在目标停止。无合法能源／制热能力时，自然交换可以越过目标，不能免费裁回。例如冷柜目标−5而外界−20，基础制冷柜仍会自然变得低于−5。

### 每段能量与供能次序

~~~text
E = P × 实际付费时长τ / 60000 Wd
可支付τ = 实际可用Wd × 60000 / P
液耗 = 实际由液体承担的制冷E / 360
~~~

每步先支付实际生命支持，再分配热控。按目标到达、能源耗尽和自然跨目标等事件拆段：先电网／同一内电，供冷不足且备用允许时才用同一液仓；制热与供气不能用液体接力。没有支付的余时只被动演进，不重复扣电液，也不拿计划负载冒充原生已付款。

地图接网沿原生实际结算回执，不能再手扣一次已参与电网的内电。面板区分当前阶段需求、已结算热控、生命支持、自放电及电池净流量。

## 已达目标后的续航

稳态温差Δ=|实际外温−目标|，P_hold=4.8ΔM W。下表只描述已达目标后的持续维持，不包含最初拉温的120W项。

~~~text
满内电维持续航 = 电池容量 / (P_hold + L_support + 自放电功率) 游戏日
L_support：CREAM实际住客／有效休息准备且启用为80W，其余0W
基础：360Wd、5W；GARLIC后：720Wd、4W
液体维持耗量 = P_hold / 360 单位／游戏日（仅实际液体供冷时）
满液仓维持续航 = 仓量 × 360 / P_hold 游戏日
~~~

**电池公式条件：** 不接外网、不供其他负载，环境／目标恒定，连续足额维持，无EMP／故障／原生网启停等待。接网可能充电、给其他设备供电或与其他电池分担，不直接用本表推断净流量。

**液体公式条件：** 备用开启、没有可用电力，且实际需供冷；有电时普通制冷液耗为0。需要升温时液体不能支付，显示无可用制热电源。∞只表示当前不消耗，不表示无限供热或下一次机动免费。电池自放电与生命支持不转嫁给冷却液。

## 跳跃与世界发射

都直接扣**同一冷却液仓**，不要求先开启温控备用或视觉悬浮，电池不能代付。研究没有液耗折扣，费用不按载荷质量另加价。

### HOPS地图跳跃

`单柜费用 = 0.05 + 0.003 × d`

`d`为起终逻辑格的水平欧氏直线距离，不是寻路距离；须不同格且≤35格，斜向距离不一定为整数。飞行时长为ceil(max(1,d/9)×60)tick，35格为234tick／3.9标准秒；旧已在途近场载体沿已保存时长完成。

| 距离d | 单柜消耗 |
|---:|---:|
| 10格 | 0.080单位 |
| 20格 | 0.110单位 |
| 35格 | 0.155单位 |

### SALT世界发射（含整队）

`d`为起点投影到目标层后的原生WorldGrid遍历距离，不是地图格或屏幕像素；同投影跨层可为0，同层同格不是新航程。

同25地表格仍为1.075单位；满8液做60地表格往返共4.6，余3.4，未计途中温控。允许液体恰好足够的单程，不强制预留返航；目标仍须合法，DILL不扩大射程或座位，自动补入的液体来自真实瓶装货物。聚落赠礼后留柜也只收单程，不自动返航。

## 实现依据

- `Mod/Defs/ThingDefs/Cabinet.xml`：基础属性、成本与电池／液仓。
- `Mod/Defs/ResearchProjectDefs/SPICE.xml`：升级profile参数。

- `Mod/Defs/Transporters.xml` 与 `Source/FAF/Transport`：距离、载荷、机动费用及共用冷却。

面板电池ETA来自实际储能差分，包含自放电和电网充放；液体ETA来自当前正在选用的供能速率。二者是当前条件外推，不预言未来天气、换目标或下一次机动。

实际耗电来自资源层结算观察，登记负载、电池净流量、热控／生命支持／自放电分项分别表达；缺样显示未知，不将需求量冒充实付。模型表格用于对比，不代替变化环境中的实时预测。


## 世界航程曲线

### 同一时间表驱动位置与预计到达

默认峰值为 **0.00015 rad/tick**，前 **30%** 时间平滑加速，中段巡航，最后 **8%** 时间快速平滑减速。速度在分段接点连续，实际进度与显示位置采用同一积分结果。

- 路线角度θ由原生球面距离计算，输入为投影前冻结的真实出发单位方向和目标中心方向；射程／液费仍使用目标层投影图距，二者不混用。
- 真实出发方向、路线参数、跨层预算、出发游戏tick、总时长和算法版本在提交时冻结并保存。
- `At(elapsedTicks)` 一次返回进度、速度和剩余 tick，供实际航程和 ETA 共用。
- 同层最短 **1200tick**；跨层分别加 **5400tick入轨／900tick返地**，不套同层下限。严格θ=0时为90／15标准秒；投影同格不保证真实θ为零。地图起降及生成等待另计。
- 暂停／倍速沿游戏 tick 工作。采样绝对积分值，不逐 tick 累加速度。

### 解析曲线与峰值约束

令加速占比 a=0.30，减速占比 b=0.08，u 为归一化时间：

~~~text
H(x) = 3x² − 2x³
J(x) = x³ − x⁴/2

h(u) = H(u/a)                     u < a
       1                           a ≤ u ≤ 1−b
       1−H((u−1+b)/b)            u > 1−b

Q(u) = a·J(u/a)                                      u < a
       a/2 + u−a                                    a ≤ u ≤ 1−b
       a/2 + (1−b−a) + b·[x−J(x)]                  u > 1−b
       其中 x=(u−1+b)/b

A = 1−(a+b)/2 = 0.81
N_angle = ceil(θ / (Vmax·A))
T = max(1200, N_angle)                  同层
T = N_angle + B                        跨层：入轨B=5400，返地B=900
P(u) = Q(u)/A
实际速度 = θ/(T·A) · h(u)
~~~

角航时须按面积A修正。总时长含短途下限或跨层预算后，仍以θ/(T·A)作为本航程实际峰值，不超过Vmax；不把附加基时误做强制超速或第二段进度。

以恒速 **0.00025 rad/tick** 为比较基准，忽略整数取整与最短时长影响时，本模型同层长途平均速度为基准 **0.486倍**，时长为约 **2.057613倍**。该比较忽略下限及附加跨层预算，不是实测全流程比例。
