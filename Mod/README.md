# N.S.I.F Extend : These fridges are absolutely can FLY !!

**涅瓦莲睡冰箱扩展：冰箱！当然！会飞！**

简称 **F.A.F.**；N.S.I.F. 指前置睡冰箱模组。

## 安装

退出游戏，将运行包中的 `FAF_FridgesAbsolutelyFly` 放入 `RimWorld/Mods`，只保留一个安装副本。GitHub玩家使用发行ZIP，不将源码ZIP当作运行包。

启用顺序：**Harmony → Humanoid Alien Races → Nivarian Race → Nivarian Sleep In Fridges QWQ → F.A.F.**。

同包支持RimWorld 1.6／1.7。Odyssey仅用于轨道功能，不是其余玩法的前置。

## 开始使用

- 完成T.O.F.U，让前置认可的冰箱悬浮；旋转单独开关，稳定悬浮只减少起伏。
- 自带冷柜按不含柜壳的净载荷限制储存与运输；T.O.F.U减轻柜壳的携带重量，内物全重另计，不增加远行队负重额度。
- 在涅瓦莲上行页找到冷柜研究。便携睡垫无需科研，可独立使用，也可选择原睡垫装柜；主仓有货时先确认清仓。
- 用温控按钮设目标，用货物管理按钮查看人货；拉温与维持分段耗能，缺少合法能源时自然回温。温控面板打开时，未在数框输入仍可暂停／变速。
- 用复合资源表调整补液目标。电力可制冷，后续还可制热和供气；冷却液只供冷及机动。自动供液需D.I.L.L，默认关闭。
- 柜床仅供涅瓦莲；S.A.L.T后其他种族可登舱，每柜0或1个活乘员，活乘员与遗体互斥。
- 卸下前先取消装载、清空运输舱并让住客离柜；主冷藏物品和睡垫可随原柜保留。远行队自动进食／交易使用普通库存，需先取出柜内相应物品。

完整[机制指南](https://github.com/Coahuilite/FridgesAbsolutelyFly/blob/main/Docs/MECHANICS.md)包含后期科研剧透；[更新日志](https://github.com/Coahuilite/FridgesAbsolutelyFly/blob/main/Docs/CHANGELOG.zh-CN.md)列出各版本变化。
