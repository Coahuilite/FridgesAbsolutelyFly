**涅瓦莲睡冰箱扩展：冰箱！当然！会飞！**

经涅瓦莲工程组复核，地板并不是制冷系统的必要零件。

完成 **Project T.O.F.U** 后，**Nivarian Sleep In Fridges** 认可的冰箱可以原位悬浮，并在悬浮时旋转，里面熟睡的小龙仍能继续休息。悬浮与旋转分别控制，起飞平稳升起，落地前先端正姿态。

T.O.F.U 研发只用普通钢铁和零部件；对涅瓦莲家用冷柜，还能减轻柜壳的携带重量，里面的人货仍按完整重量计算。

模组也提供涅瓦莲家用冷柜与便携睡垫。进一步改进归入 **SPICE 计划——Storage Preservation and Integrated Cooling Engineering，储藏保鲜与一体化制冷工程**。项目清单看起来像调料架，只是行政上的巧合。

## 安装

请安装运行包，而不是 GitHub 自动生成的源码 ZIP。退出游戏，将解压后的 `FAF_FridgesAbsolutelyFly` 放入 `RimWorld/Mods`，只保留一个安装副本。

启用顺序：

**Harmony → Humanoid Alien Races → Nivarian Race → Nivarian Sleep In Fridges QWQ → F.A.F.**

支持 **RimWorld 1.6／1.7**，**Odyssey 为可选 DLC**。冰箱兼容范围沿用前置的判定规则；包括自带冷柜在内，都需要完成 T.O.F.U 才能悬浮。
