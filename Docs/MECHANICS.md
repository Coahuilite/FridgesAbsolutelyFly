# 冷柜怎样工作

完成 T.O.F.U 后，兼容冰箱可以离开地面，里面的小龙仍能继续睡觉。这种悬浮只改变姿态；要把自带冷柜搬到别处，需要后续的近场转运或世界发射。

本页解释玩法，包含后期科研剧透。安装与基本操作见[随包说明](../Mod/README.md)。

## 悬浮不是运输

冰箱是否兼容沿用睡冰箱前置的判定。T.O.F.U 只需少量普通钢铁与零部件，不消耗涅瓦莲专属材料；可独立于自带冷柜研发，也对自带冷柜生效，未完成前不能悬浮。完成后，本模组冷柜的柜壳携带重量也会降低，打包前不必手动开启悬浮；柜内人货仍按实际重量计算。

悬浮与旋转分别控制：先升起再旋转，关闭旋转会回正，降落则先回正再降低。它们不改变占地、接线或储存，也不额外收费。稳定悬浮只减小上下起伏；精细角速度可调双向旋转，零速保持当前角度，关闭旋转才回正。

## 冷藏物品、运输货物和睡垫各用什么空间

冷柜实际持有物品，不是让物品留在地面的货架。主冷藏仓用于日常储存，运输舱用于装载发射；货物管理页将它们与住客、待登舱安排分开显示。

有空叠位不代表还能装货。主冷藏仓与运输舱共用净载荷预算，睡垫、乘员及其装备／携物都计重，柜壳不占这份额度；可装数量同时受重量和堆叠空间限制。已有超重物品不会自动丢失，可先取出减重，但恢复合格前不能继续添货或出发。同柜内部转移不重复计重，目标仓的其他储存规则仍然生效。

| 操作 | 用途 |
| --- | --- |
| 自动装载 | 让搬运工按储存筛选和优先级向主冷藏仓补货 |
| 装入物品 | 点选地图物品，让角色搬入主冷藏仓 |
| 装载发射组 | 安排这次运输的人员、动物及运输货物 |
| 补充冷却液 | 将实际瓶装冷却液加入内置液仓，不是把货物移动到另一储物格 |

便携睡垫无需科研即可制作，也可独立作睡袋。装柜时选择原睡垫，由角色搬运安装；主仓有货会先询问是否移出，取消确认不动货物。安装后的睡垫独占主冷藏仓，不挤掉独立运输舱；它保留材质、品质和耐久，并给柜床带来休息及医疗增益。

卸下冷柜仍保留原柜、主仓内容或睡垫，以及资源和温控设置。远行队携带质量为有效柜壳加实际内容物，不是货物页上的净载荷；T.O.F.U 只减轻柜壳，不给远行队增加负重额度。远行队自动进食、用药和交易使用普通库存，需要先把相应物品从柜内取出。

## 冷冻和冷藏由内温决定

柜内物品按冷柜的实际内部温度处理原生腐烂、温度损坏与孵化。查看物品详情即可区分冷冻、冷藏和正常腐烂，并读取速率与进度。

冷冻不会清除已有腐烂，也不暂停物品的全部老化机制；孵化物仍可能被低温损坏。打包、携带、航程和等待回收不会暂停冷链，也不会免费维持恒温。

## 电、液和空气不能互相替代

接网时，内置电池可充电或向电网供电；离网则使用同一份储能。关闭温控不会把电池从电网断开。

温控分为拉温和到点维持。拉温按当前内温选择方向，有持续基础负荷；不利外温差越大，额外需求越高，有利的自然换热则保留。到达目标立即撤掉拉温项，转为维持负荷；外温恰好等于目标时，也能把偏离的内温主动拉回。

初期调节器只制冷，C.R.E.A.M 后才开放制热和柜内气氛维持。优先实际电力，供冷不足且开启备用后才用冷却液；能源只够一部分时间就只控制这一部分，其余时间自然换热。**冷却液不能升温，也不能供气。** 没有可用制热时，寒冷外界仍可能让柜内低于设定温度，目标不是免费温度下限。

C.H.I.V.E 改善被动保温，不直接降低有偿维持负荷。G.A.R.L.I.C 延长电池使用时间，B.A.S.I.L 扩大液仓；P.E.P.P.E.R 提高拉温速度及单位时间的耗电／耗液，开着时维持负荷也更高。完成扩容不会免费补电、补液或修复耐久。

温控开启时，C.R.E.A.M 为活住客或有效休息准备用电维持气氛，普通空柜不付这笔负荷。失电后压力逐渐趋近外界，失去有效温控后温度也会变化；太空中不能靠剩余冷却液无限保护乘员。

## 怎样读懂温控面板

内温是当前状态，目标是希望达到的温度；外温决定环境负荷。温控需求、本柜实际耗电与电池净流量是不同读数：电池还可能自放电、充电或给其他设备供电。

预计续航按当前条件外推。未知表示尚无足够读数，耗尽表示对应资源已空，∞表示当前没有消耗，不代表下一次发射免费，也不代表冷却液能够供热或供气。

窗口可拖动、可关闭，打开时仍可控制暂停和倍速；数框聚焦时数字优先用于输入。货物管理是独立页面，不必为了查看人货打开温控。

## 补液目标只设一次

资源表和温控面板修改的是同一个目标，人工补液和 D.I.L.L 自动供液都遵守它。调低目标不排出现有液体；不足以容纳一整瓶时等待，不为凑满吞掉余量。

人工补液不需要 D.I.L.L。研究后的自动供液默认关闭：开启后先用本柜主仓或运输货物中的瓶装储备，储备用尽且仍需补液时，再让地图上的角色实际搬运外部物资。它不取乘员私人背包或他柜库存，也不会替玩家开启温控或备用制冷。

## 床位与乘员不是同一种资格

冷柜床始终只供前置认可的涅瓦莲使用。S.A.L.T 后，其他种族也能作为乘员登舱，但不能因此使用柜床；动物占用同一席位，不是额外随身货物。

每柜可以没有活乘员，或有一个活乘员。遗体可作货物，但与活乘员互斥。已有住客和有效登舱安排都会占席位，货物及乘员装备也计入载重。

“结束休息”与“出舱”分开：结束休息可以继续留舱，快速离柜只移出所选使用者。危险温度或真空中的出舱需要确认，缺电不会自动弹人。途中不能对外取放或出舱；住客饿了会按饮食规则吃本人或同柜的实际食物。

## 让同一台冷柜抵达

H.O.P.S 用于地图内近场转运，选合法落点即起飞，旋转键选择落地朝向，建筑虚影显示当前柜型的首尾方向；最远35格飞行约3.9标准秒，短程至少1标准秒，暂停／倍速照常作用。落点检查完整柜体及交互空间；可通行草类和污渍可保留，树木、建筑冲突、屋顶或不承重地面可能阻止着陆。

S.A.L.T 解锁世界发射与多柜编组。报价按实际路线显示距离、费用、余液和预计世界段时间；各柜从自己的液仓支付，不共享虚拟余额。射程及费用沿目标层格数，飞行时间沿真实起终方向计算，不是固定每格几秒。

世界段先缓慢加速，抵达前快速减速；同层至少20标准秒。入轨在横向航时外加90标准秒，返地加15标准秒，不另套同层下限；地图起降和生成等待另计。新时间规则只用于新出发，旧在途沿保存计划完成。跳跃与世界发射共用冷却，途中温控、气氛及乘员需求照常推进，允许没有返程余液的合法单程。

正常落图会展开原柜并默认让乘员留舱；明确选择组成或交给远行队时，人员与柜体进入真实队伍，人员此时已离舱。Odyssey 只开放轨道路线，不是其他玩法的前置；轨道驻留仍需实际能源与环境保护；柜体被毁就失去保护。

## 自主投送与回收

S.A.L.T 与 D.I.L.L 都完成后，可无人货运或让一只己方动物独占一柜自主运输。普通自主目的地须已有合法接收地图，不因此开放无人首次探索或攻击，也不生成空的或纯动物步行远行队。

向非敌对外国聚落自主投送会赠送实际内容物，原柜、睡垫和内置资源留当地供后续取回；向敌对聚落投送则须确认放弃柜体及全部载荷。自动补液可能先消耗待赠冷却液，礼单以实际剩余为准。

途中全员死亡不一定迫降：合法目的地仍可接收柜体与遗体。无法正常交付的余物才留在持久冷柜迫降点，轨道失败使用可回收的地表出口。派另一支玩家远行队右键落点回收，接纳不了的部分留原处；该操作不提供逐物数量选择。等待与存读档保留原柜状态，已经交付的内容不会重新生成。
