# 更新日志

本文件记录 F.A.F.（Fridges Absolutely Fly）各公开版本的显著变更。[English](CHANGELOG.md)

## 更新日志规则

- 按版本倒序追加，最新版本在前，未发布条目置顶；不覆盖已发布历史。
- 未发布标题使用`未发布 — X.Y.Z`；发布时改为`[YYYY-MM-DD HH:MM UTC+8] 版本 X.Y.Z`，填写实际发布时间。
- 分类使用新增、变更、修复、废弃、移除、安全，另可使用打包、说明；空分类不保留，破坏性变更置顶说明影响与所需操作。
- 首次公开只列首次提供的功能，不把未公开试玩中的修复、移除或迁移写成公开版本变更。
- 一条记录一个显著的玩家变化；详细机制与操作放在指南，不把研发过程写进版本历史。
- 中英文逐条同步；后续版本与上一公开版本比较，创意工坊首次上传仅在实际首次上传时记录。

## 未发布 — 0.1.0

首个公开版本：让兼容冰箱悬浮与旋转，并加入可逐步改装的涅瓦莲家用冷柜。

### 新增

- 通过 Project T.O.F.U 解锁前置睡冰箱模组认可的冰箱储存器原位悬浮与旋转，研发只需少量普通钢铁与零部件，不消耗涅瓦莲专属材料；自带冷柜也遵守同一科研门槛。
- 通过 T.O.F.U 将自带冷柜的有效柜壳重量由45降至5千克，远行队携带时同样生效，不要求打包前开启悬浮；内容物保持全重。
- 分别控制悬浮与旋转，平滑升起、回正和降落；不改变建筑占地、接线或储存功能，不额外消耗电力或冷却液。
- 让睡眠者、睡垫和柜内物品随柜运动，同时保留前置睡眠能力与角色正常大小。
- 提供透明的涅瓦莲家用冷柜，占地1×2，转向后2×1；支持储存筛选、卸下、携带、重新安装和拆解。
- 在主冷藏仓内实际保存12叠物品，按柜内温度影响原生腐烂、温度损坏和孵化；物品详情显示冷冻／冷藏状态、腐烂速率、进度及剩余时间。
- 在打包、远行队携带、飞行及等待回收时保留原柜、内容物、资源和设置，并继续推进温控、资源消耗与易腐物变化；内容物计入实际质量。
- 提供无需科研的涅瓦莲便携睡垫，以45份布料／皮革和5份涅瓦莲鳞片制作；可独立作为有品质的睡袋，卸下后显示卷起外观。
- 允许将铺开或打包的睡垫装入冷柜；主仓有货时先确认清仓，再由殖民者搬运安装，保留原垫材质、品质和耐久。
- 让安装的睡垫独占主冷藏仓，并为柜床提供品质、休息和医疗增益；独立睡垫仅提供品质对应的休息效果。
- 将柜床限定为涅瓦莲使用，继承前置睡眠效果；本柜的前置额外冰核恢复按实际内温低于10°C判断，离网余冷也可满足。
- 提供360瓦日、100%充电效率的内置电池，支持相邻导线、远距自动接线、接网充放电及离网运行。
- 将有偿拉温与到点维持分开：普通模式拉温有持续120瓦基础项及每度不利外温差4.8瓦，到点撤掉拉温项；有利自然换热保留，电力与冷却液按同一真实付费时段供冷，未付费时段只自然换热。
- 提供5单位涅瓦莲冷却液储备，供备用制冷、跳跃和发射共用；每单位等效360瓦日制冷量，备用默认关闭，仅在电力无法供冷时使用，不能制热或供气。
- 提供可拖动的冷藏调节器，目标范围−30～10°C、默认−5°C；支持滑条和数字输入，窗口打开且未在输入时仍可暂停与调整倍速。
- 提供独立货物管理页，分别显示冷藏物品、运输货物、住客及登舱／休息安排，并按所在场景支持搜索、保鲜详情与物品取放。
- 提供复合电量／冷却液表，允许拖动补液目标；资源表、温控和人工补液共用同一目标，地图柜与可选中的柜体包裹均可操作。
- 允许从本柜冷藏仓和运输货物补充整瓶冷却液；外部补给通过殖民者实际搬运，不取乘员私有库存。
- 提供休息、结束休息及快速离柜操作；危险环境出舱需确认，缺电不自动弹出人员，正常航程抵达后默认留舱。
- 让舱内住客按正常饮食规则食用本人或同柜的实际食物；地图柜床睡眠者继续使用前置的偷吃规则。
- 加入 SPICE（Storage Preservation and Integrated Cooling Engineering／储藏保鲜与一体化制冷工程）科研路线，使用涅瓦莲上行系统与实际材料费用逐组解锁改装。
- 让家用冷柜科研与 T.O.F.U 彼此独立、提前可见，均以涅瓦莲低温合成为前置；后续改装在两者完成后逐组开放，S.A.L.T 为最终项目。
- 通过 C.H.I.V.E 将被动换热减半，不降低主动温控负荷。
- 通过 W.A.L.N.U.T 将最大耐久由260提高至390，不补充当前耐久。
- 通过 O.N.I.O.N 将主冷藏仓由12叠扩至24叠，不减少物品质量。
- 通过 B.A.S.I.L 将液仓由5单位扩至8单位，不免费补液。
- 通过 C.R.E.A.M 解锁制热、−30～40°C智能恒温器和柜内气氛维持；窗口显示内外环境、资源、消耗及预计续航，并随可用屏幕空间调整布局。
- 在温控开启时，为活住客或有效的休息准备提供80瓦柜内气氛维持；失电后压力逐渐趋外，住客按实际柜内温度和真空度承受环境影响。
- 通过 G.A.R.L.I.C 将电池容量由360提高至720瓦日、自放电由5降至4瓦，并解锁减少起伏的稳定悬浮与可输入双向角速度；扩容不补电。
- 通过 P.E.P.P.E.R 增加喷口外观与可选快速稳温，主动温控能力及对应电力／制冷耗液同时提高至3倍。
- 通过 H.O.P.S 解锁最远35地图格的近场跳跃，耗液为 `0.05 + 0.003 × 距离`；选点时以建筑虚影预览当前柜型及可旋转的落地朝向，并以原柜完成起降动画，按正常速度9格／秒、最短1秒计时，最远约3.9秒。
- 通过 D.I.L.L 解锁默认关闭的自动供液，优先用本柜整瓶储备；储备耗尽且仍需补液时，再由殖民者搬运外部物资。
- 通过 S.A.L.T 解锁单人太空梭改装外观、地图多柜编组及整支远行队的世界发射；其他种族可登舱，但不能使用涅瓦莲柜床。
- 限定每柜0或1个活乘员，动物同样占用唯一席位；无活乘员时遗体可作货物，活乘员与遗体不能同柜。
- 冷藏储存与运输共用每柜250千克净载荷，不含柜壳，包含已装睡垫、乘员、装备和携物；接收数量同时受重量及堆叠空间限制，同柜转移不重复计重。已有超重内容保留供取出，恢复合格前不新增载荷或出发；另检查席位、燃料和未完成装载。
- 提供最远60目标地表格的世界航程，每柜单程耗液为 `0.20 + 0.035 × 距离`；允许不预留返航冷却液的单程飞行。
- 在启用 Odyssey 且完成 C.R.E.A.M 后开放轨道路线，最远10目标轨道格；地表入轨耗液为 `1.00 + 0.70 × 距离`，轨道间为 `0.20 + 0.70 × 距离`，返地表沿地表费用。
- 世界计时与路径采用真实原始出发方向，峰值上限0.00015弧度／tick，平滑加速并在抵达前减速，预览与在途共用预计时间。按正常速度，同层至少20秒，入轨在角航时外加90秒、返地加15秒，跨层不套同层下限；已有在途沿保存计划完成。跳跃与世界发射共用每柜2500 tick冷却，按钮显示剩余冷却。
- 在 S.A.L.T 与 D.I.L.L 均完成后开放无人货运及己方动物自主运输；普通自主路线限已生成、可接收的地图，不生成无人或纯动物步行远行队。
- 向非敌对外国聚落自主投送时赠送实际内容物，留下原柜、睡垫与内置资源供后续回收；向敌对聚落投送需确认放弃柜体及全部载荷。
- 为无法接收的载荷及途中全员死亡保留持久冷柜迫降点，支持其他远行队回收及部分接纳；存读档保留原余物，不重复生成已交付内容。
- 提供英文与简体中文文案、分阶段柜体外观、专用动作图标及中英封面。
- 在开发者模式提供电量充满／清空、冷却液加满／清空四个独立按钮。
